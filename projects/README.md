# 示范工程（`projects/`）

本目录存放 **`.pond` 用户工程**，每个子目录须含 `project.json`。

## 正式示范（v1.0.0）

| 目录 | 用途 | 默认场景 |
|------|------|----------|
| [`pvaec-细胞演化/`](pvaec-细胞演化/) | PVAEC 细胞演化 SR 演示（入门 + 挑战） | `main_scene.pond` |
| [`织机教程-迷你Roguelike/`](织机教程-迷你Roguelike/) | 织机引擎教学：ScriptBase + 2D Roguelike | `dungeon_01.pond` |

打开方式：`python main.py` → **文件 → 打开项目** → 选择上表目录。
