# 基于记忆继承算法的AI生命体模拟器

[![Python Version](https://img.shields.io/badge/python-3.12+-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## 📖 项目概述

本项目是一个创新的AI生命体模拟器，实现了基于**记忆继承算法**的智能进化系统。该模拟器从简单的AI生命体开始，通过学习控制身体、积累经验，并将经验以结构化记忆的形式遗传给后代，探索智能行为的涌现和进化过程。

核心功能是**AI生命体记忆继承模拟**，验证记忆遗传机制的有效性，观察智能行为的涌现和进化。

## 🎯 核心功能

### 记忆继承算法
- 实现了结构化记忆的遗传机制
- 支持AI生命体通过经验学习和记忆遗传进化
- 可观察智能行为的涌现过程
- 优化的记忆检索和匹配算法，提高运行效率

### 单模式模拟系统
- **AI生命体模式**：从简单细胞开始，通过学习和记忆遗传进化

### 可视化界面
- 基于Pygame的实时可视化模拟
- 支持模拟速度调节和暂停/继续
- 实时显示模拟统计数据
- 增强的按钮交互效果和状态显示

### 编辑器支持
- 传统Pygame编辑器，提供基本编辑功能
- 全新PyQt6编辑器原型，提供IDE风格的编辑体验
- 支持项目管理、生物编辑和属性调整

### 优化的性能
- 核心算法性能优化，支持更大规模模拟
- 记忆管理优化，防止内存无限增长
- 高效的记忆检索和匹配机制

### 可扩展架构
- 模块化设计，支持添加新的物种和行为
- 易于扩展的记忆遗传机制
- 支持自定义环境参数

## 🚀 快速开始

### 环境要求

- Python 3.12+
- 支持的操作系统：Windows、macOS、Linux

### 安装依赖

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd ai_organism_based_on_inheritance_algorithm
   ```

2. **创建虚拟环境（可选但推荐）**
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS/Linux
   source .venv/bin/activate
   ```

3. **安装依赖**
   ```bash
   # 使用uv安装（推荐，更快）
   uv install

   # 或使用pip
   pip install -r requirements.txt
   ```

### 运行模拟

```bash
# 启动模式选择器
python main.py
```
或者 uv run

在模式选择器中，您可以选择运行：
1. **Tool继承算法模拟器** - 模拟AI生命体通过工具学习和记忆遗传的进化过程
2. **AI生命体编辑器** - 基于PyQt6的可视化编辑器，用于创建和编辑AI生命体
3. **退出系统**

## 🎮 使用说明

### Tool继承算法模拟器

#### 控制键
- `Space`：暂停/继续模拟
- `+`：增加模拟速度
- `-`：降低模拟速度
- `Q`：退出模拟

#### 模拟内容
- 观察AI生命体如何通过传感器感知环境
- 查看AI生命体如何通过执行器与环境交互
- 观察记忆如何在代际间遗传
- 查看智能行为的涌现和进化过程

### AI生命体编辑器

#### 功能特点
- 基于PyQt6的现代化GUI界面
- 支持创建和编辑AI生命体的结构和属性
- 可视化编辑细胞膜、传感器、执行器和中枢管理器
- 支持连接和配置各组件之间的关系
- 实时预览AI生命体的结构

## 📋 核心模块说明

### 1. Core模块

**核心组件定义和实现**
- `event_system.py`：事件系统，用于组件间通信
- `memory.py`：记忆基因实现，支持结构化记忆存储和遗传
- `organism.py`：AI生命体基类，定义了生命体的基本属性和行为

### 2. Tools模块

**AI生命体的工具组件**
- `actuators.py`：执行器工具，如肌肉、纤毛等，用于与环境交互
- `base.py`：工具基类，定义了所有工具的通用接口
- `central_brain.py`：中枢管理器，实现AI控制和决策
- `connection.py`：连接类，用于组件间的信号传递
- `membrane.py`：细胞膜实现，作为细胞边界和交互接口
- `sensors.py`：传感器工具，如触觉、光感等，用于感知环境

### 3. Simulation模块

**模拟系统实现**
- `simulation.py`：基础模拟实现，提供模拟框架
- `tool_inheritance_simulation.py`：Tool继承算法模拟，实现基于工具的AI生命体进化
