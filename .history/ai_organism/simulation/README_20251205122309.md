# Simulation模块说明文档

## 模块概述

simulation模块是AI生命体模拟器的核心模拟系统，负责管理AI生命体的生命周期、环境交互和进化过程。该模块实现了模拟的主要逻辑，包括种群管理、环境更新和进化算法。

## 核心设计理念

构建一个**以"结构化记忆遗传"为核心机制、以"可扩展工具"为身体组件、以"AI学习控制"为驱动力的数字生命进化模拟沙盒**，验证记忆继承算法的可行性和有效性。

## 核心功能

### 1. 基础模拟框架 (simulation.py)

实现了模拟系统的基础框架，提供了模拟的核心功能。

#### 主要功能
- 环境管理
- 生命体种群管理
- 模拟循环控制
- 可视化渲染

#### 核心类
- `Simulation`: 模拟系统的基类，定义了模拟的基本接口和功能

#### 使用示例
```python
from ai_organism.simulation.simulation import Simulation

# 创建模拟实例
simulation = Simulation(width=800, height=600)

# 初始化模拟
simulation.initialize()

# 运行模拟循环
running = True
while running:
    for event in simulation.get_events():
        if event.type == simulation.QUIT:
            running = False
    
    simulation.update()
    simulation.draw()
    simulation.tick()
```

### 2. Tool继承算法模拟器 (tool_inheritance_simulation.py)

实现了基于工具继承算法的AI生命体模拟，是核心的模拟实现。

#### 主要功能
- 工具系统的模拟
- 记忆遗传算法的实现
- AI学习和进化过程
- 实时可视化界面

#### 核心类
- `ToolInheritanceSimulation`: 基于工具继承算法的模拟类，实现了完整的AI生命体进化模拟

#### 使用示例
```python
from ai_organism.simulation.tool_inheritance_simulation import ToolInheritanceSimulation

# 创建Tool继承算法模拟实例
simulation = ToolInheritanceSimulation(width=800, height=600)

# 初始化模拟
simulation.initialize()

# 运行模拟
simulation.run()
```

## 模拟流程

### 1. 初始化阶段
1. 创建模拟环境
2. 生成初始AI生命体种群
3. 设置模拟参数
4. 初始化可视化界面

### 2. 模拟循环
1. **输入处理**：处理用户输入和系统事件
2. **环境更新**：更新环境状态（食物分布、资源变化等）
3. **生命体更新**：
   - 感知环境
   - 决策和行动
   - 能量管理
   - 记忆更新
   - 繁殖和死亡
4. **进化处理**：
   - 选择优势个体
   - 执行记忆遗传
   - 应用变异机制
   - 更新种群
5. **可视化渲染**：绘制环境、生命体和状态信息
6. **性能监控**：显示FPS和实体数量

### 3. 交互控制

| 按键 | 功能 |
|------|------|
| Space | 暂停/继续模拟 |
| + | 增加模拟速度 |
| - | 降低模拟速度 |
| Q | 退出模拟 |
| 鼠标左键点击生物 | 查看详细信息 |
| 鼠标左键点击空地 | 添加食物 |

## 模块间关系

simulation模块与其他模块的关系：
- 依赖core模块的生命体和记忆系统
- 依赖tools模块的工具组件
- 依赖environment模块的环境系统
- 与editor模块交互，支持编辑功能

| 环境参数 | 环境大小 | 800x600 |

| 生命参数 | 最大年龄 | 500 |

## 设计原则

- **模块化设计**：模拟系统分为多个层次，便于维护和扩展
- **可配置性**：支持通过参数调整模拟行为
- **可视化优先**：提供直观的可视化界面，便于观察和分析
- **性能优化**：采用高效的算法和数据结构，支持大规模模拟

## 性能优化

1. **空间划分**：使用四叉树优化碰撞检测
2. **异步更新**：分离模拟计算和可视化渲染
3. **实体池**：重用实体对象，减少内存分配
4. **按需更新**：仅更新可见区域的实体
