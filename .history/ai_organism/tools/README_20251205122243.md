# Tools模块说明文档

## 模块概述

tools模块是AI生命体模拟器的工具系统，定义了AI生命体的各种功能组件。该模块实现了统一的工具接口和多种具体工具类型，支持AI生命体与环境的交互。

## 核心设计理念

将生物的基本功能单元抽象为"工具"，所有"工具"的核心是一个**输入输出函数**。这种设计确保了系统的**高度可扩展性**，可以轻松添加新的功能单元。

## 工具类型

| 工具类型 | 功能描述 | 输入 | 输出 | 示例 |
|---------|---------|------|------|------|
| 传感器工具 | 感知环境信息 | 环境信息 | 神经信号 | 触觉传感器、光感传感器 |
| 效应器工具 | 执行物理动作 | 控制信号 | 物理力 | 肌肉效应器、纤毛效应器 |
| 中枢管理器 | AI控制和决策 | 传感器信号 | 控制信号 | 中枢大脑 |
| 细胞膜 | 细胞边界管理 | 环境信息 | 控制信号 | 细胞边界 |
| 连接 | 信号传递通道 | 输入信号 | 输出信号 | 单向连接、双向连接 |

## 核心功能

### 1. 工具基类 (base.py)

定义了所有工具的通用接口和基础功能。

#### 主要功能
- 统一的工具接口定义
- 基础属性管理
- 通用的工具方法

#### 核心类
- `Tool`: 所有工具的基类，定义了工具的基本接口

#### 使用示例
```python
from ai_organism.tools.base import Tool

# 自定义工具类
class CustomTool(Tool):
    def __init__(self, tool_id: str, position: tuple):
        super().__init__(tool_id, position)
        # 自定义初始化
    
    def process(self, input_value):
        # 实现工具的处理逻辑
        return input_value * 2
    
    def draw(self, surface):
        # 实现工具的绘制逻辑
        pass

# 创建自定义工具实例
custom_tool = CustomTool("custom_1", (100, 100))
```

### 2. 执行器工具 (actuators.py)

实现了各种效应器工具，用于AI生命体与环境的物理交互。

#### 主要功能
- 肌肉效应器：实现线性运动
- 纤毛效应器：实现旋转运动

#### 核心类
- `MuscleActuator`: 肌肉效应器，产生线性推力
- `CiliaActuator`: 纤毛效应器，产生旋转力

#### 使用示例
```python
from ai_organism.tools.actuators import MuscleActuator, CiliaActuator

# 创建肌肉效应器
muscle = MuscleActuator("muscle_1", (100, 100))

# 创建纤毛效应器
cilia = CiliaActuator("cilia_1", (200, 200))

# 使用效应器
muscle.process(0.5)  # 产生50%强度的推力
cilia.process(0.3)   # 产生30%强度的旋转力
```

### 3. 中枢大脑 (central_brain.py)

实现了AI生命体的决策中心，负责接收传感器输入并生成控制信号。

#### 主要功能
- 传感器信号处理
- 基于记忆的决策
- 控制信号生成

#### 核心类
- `CentralBrain`: 中枢大脑类，实现AI决策逻辑

#### 使用示例
```python
from ai_organism.tools.central_brain import CentralBrain
from ai_organism.core.memory import MemorySystem

# 创建记忆系统
memory_system = MemorySystem()

# 创建中枢大脑
brain = CentralBrain("brain_1", (150, 150), memory_system)

# 处理传感器输入
sensory_input = [0.5, 0.3, -0.2]
control_signals = brain.process(sensory_input)
```

### 4. 连接系统 (connection.py)

实现了工具间的信号传递机制，支持不同工具之间的通信。

#### 主要功能
- 单向连接
- 双向连接
- 信号强度调节

#### 核心类
- `Connection`: 连接类，实现工具间的信号传递

#### 使用示例
```python
from ai_organism.tools.connection import Connection
from ai_organism.tools.sensors import TouchSensor
from ai_organism.tools.actuators import MuscleActuator

# 创建传感器和效应器
sensor = TouchSensor("sensor_1", (100, 100))
actuator = MuscleActuator("actuator_1", (200, 200))

# 创建连接
connection = Connection("conn_1", sensor, actuator, strength=0.8)

# 传递信号
output = connection.process(0.5)
```

### 5. 细胞膜 (membrane.py)

实现了AI生命体的边界管理，负责与环境的交互和保护内部组件。

#### 主要功能
- 细胞边界定义
- 与环境的物质交换
- 保护内部组件

#### 核心类
- `Membrane`: 细胞膜类，实现细胞边界管理

#### 使用示例
```python
from ai_organism.tools.membrane import Membrane

# 创建细胞膜
membrane = Membrane("membrane_1", (150, 150), radius=30)

# 检测碰撞
collision = membrane.check_collision((160, 160))

# 处理环境交互
membrane.process(0.0)
```

### 6. 传感器工具 (sensors.py)

实现了各种传感器工具，用于AI生命体感知环境信息。

#### 主要功能
- 触觉传感器：检测碰撞
- 光感传感器：感知光照强度

#### 核心类
- `TouchSensor`: 触觉传感器，检测与其他物体的碰撞
- `LightSensor`: 光感传感器，感知环境光照强度

#### 使用示例
```python
from ai_organism.tools.sensors import TouchSensor, LightSensor

# 创建触觉传感器
touch_sensor = TouchSensor("touch_1", (100, 100))

# 创建光感传感器
light_sensor = LightSensor("light_1", (200, 200))

# 使用传感器
touch_value = touch_sensor.process(0.0)  # 检测碰撞
light_value = light_sensor.process(0.0)  # 感知光照
```

## 模块间关系

tools模块与其他模块的关系：
- 依赖core模块的基础结构
- 被simulation模块用于构建AI生命体
- 与environment模块交互，感知和影响环境

## 设计原则

- **统一接口**：所有工具实现相同的接口，便于系统管理
- **可扩展性**：可以轻松添加新的工具类型
- **低耦合**：工具间通过连接系统通信，减少直接依赖
- **模块化**：不同类型的工具分开实现，便于维护

## 性能考虑

- 工具处理逻辑尽量简单高效
- 传感器更新采用按需更新策略
- 连接系统使用高效的信号传递机制

## 扩展建议

1. 添加更多传感器类型：温度、湿度、声音等
2. 添加更多效应器类型：更复杂的运动机制
3. 实现更高级的中枢大脑算法
4. 添加工具组合和层级结构
