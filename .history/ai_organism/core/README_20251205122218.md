# Core模块说明文档

## 模块概述

core模块是AI生命体模拟器的核心组件，包含了系统的基础架构和核心功能。该模块定义了AI生命体的基本结构、记忆系统和事件机制，是整个系统的基础。

## 核心功能

### 1. 事件系统 (event_system.py)

事件系统实现了组件间的通信机制，允许模块间通过事件进行松耦合通信。

#### 主要功能
- 事件的发布与订阅
- 事件队列管理
- 异步事件处理

#### 核心类
- `EventSystem`: 事件系统的核心类，负责事件的注册、发布和处理

#### 使用示例
```python
from ai_organism.core.event_system import EventSystem

# 创建事件系统实例
event_system = EventSystem()

# 定义事件处理函数
def handle_event(event_data):
    print(f"处理事件: {event_data}")

# 注册事件监听器
event_system.subscribe("test_event", handle_event)

# 发布事件
event_system.publish("test_event", {"message": "Hello, World!"})
```

### 2. 记忆系统 (memory.py)

记忆系统实现了AI生命体的记忆遗传机制，包含记忆基因的数据结构和遗传算法。

#### 主要功能
- 记忆基因的数据结构定义
- 记忆的遗传、变异和衰减机制
- 记忆的检索和匹配算法

#### 核心类
- `MemoryGene`: 记忆基因的数据结构，包含情境描述、行动模式、成功概率和记忆强度
- `MemorySystem`: 记忆系统的核心类，负责记忆的管理和遗传

#### 使用示例
```python
from ai_organism.core.memory import MemoryGene, MemorySystem

# 创建记忆基因
memory_gene = MemoryGene(
    context={"sensory_input": [0.5, 0.3]},
    action=[0.2, -0.1],
    success_probability=0.8,
    strength=1.0
)

# 创建记忆系统
memory_system = MemorySystem()

# 添加记忆
memory_system.add_memory(memory_gene)

# 检索匹配的记忆
matched_memories = memory_system.get_matching_memories({"sensory_input": [0.4, 0.2]})
```

### 3. 生命体基类 (organism.py)

organism.py定义了AI生命体的基本结构和行为，是所有AI生命体的基类。

#### 主要功能
- 生命体的基本属性管理（能量、年龄、位置等）
- 感知-决策-行动循环
- 记忆遗传和繁殖机制

#### 核心类
- `Organism`: AI生命体的基类，定义了生命体的基本属性和行为

#### 使用示例
```python
from ai_organism.core.organism import Organism
from ai_organism.environment.environment import Environment

# 创建环境
environment = Environment()

# 创建生命体
organism = Organism(environment)

# 执行生命体的生命周期
organism.update()
organism.draw()
```

## 模块间关系

core模块与其他模块的关系：
- `tools`模块依赖core模块的基础结构
- `simulation`模块使用core模块创建和管理生命体
- `environment`模块与core模块交互，提供环境信息

## 设计原则

- **高内聚**：每个组件职责明确，功能单一
- **低耦合**：组件间通过接口通信，减少直接依赖
- **可扩展**：设计允许轻松添加新的功能和组件
- **模块化**：功能划分为独立的模块，便于维护和测试

## 性能考虑

- 记忆检索算法采用高效的匹配机制，减少计算开销
- 事件系统采用异步处理，提高系统响应性
- 生命体更新采用增量计算，优化性能

## 扩展建议

1. 增强记忆系统的复杂度，支持更复杂的记忆结构
2. 扩展事件系统，支持事件优先级和过滤机制
3. 优化生命体的决策算法，提高智能水平
4. 添加更多的遗传机制，如交叉和重组
