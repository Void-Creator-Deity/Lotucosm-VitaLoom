# Editor模块说明文档

## 模块概述

editor模块是AI生命体模拟器的编辑器系统，提供了可视化的AI生命体创建和编辑功能。该模块实现了两种编辑器：基于Pygame的简单编辑器和基于PyQt6的现代化编辑器，支持AI生命体的结构设计和属性调整。

## 核心设计理念

构建一个**直观、易用、功能强大的编辑器系统**，允许用户创建和编辑AI生命体的结构和属性。编辑器应支持可视化设计、实时预览和灵活的配置选项，以促进AI生命体的创新设计和实验。

## 核心功能

### 1. 命令系统 (command.py)

实现了命令模式，支持编辑器的undo/redo功能。

#### 主要功能
- 命令的执行和撤销
- 命令历史管理
- 支持组合命令

#### 核心类
- `Command`: 命令基类，定义了命令的基本接口
- `CommandManager`: 命令管理器，负责命令的执行和历史管理

#### 使用示例
```python
from ai_organism.editor.command import Command, CommandManager

# 自定义命令类
class CustomCommand(Command):
    def __init__(self, organism, property_name, new_value):
        self.organism = organism
        self.property_name = property_name
        self.old_value = getattr(organism, property_name)
        self.new_value = new_value
    
    def execute(self):
        setattr(self.organism, self.property_name, self.new_value)
    
    def undo(self):
        setattr(self.organism, self.property_name, self.old_value)

# 创建命令管理器
command_manager = CommandManager()

# 创建并执行命令
command = CustomCommand(organism, "energy", 100)
command_manager.execute_command(command)

# 撤销命令
command_manager.undo()
```

### 2. 模板管理 (template_manager.py)

实现了AI生命体模板的管理功能，支持模板的保存、加载和共享。

#### 主要功能
- 模板的创建和保存
- 模板的加载和应用
- 模板的分类和管理

#### 核心类
- `TemplateManager`: 模板管理器，负责模板的管理和操作

#### 使用示例
```python
from ai_organism.editor.template_manager import TemplateManager

# 创建模板管理器
template_manager = TemplateManager()

# 保存模板
template_manager.save_template(organism, "template_name", "template_description")

# 加载模板
organism = template_manager.load_template("template_name")

# 获取所有模板
templates = template_manager.get_all_templates()
```

### 3. UI编辑器组件

实现了可视化的AI生命体编辑器界面，包括基于Pygame的简单编辑器和基于PyQt6的现代化编辑器。

#### 3.1 Pygame编辑器 (simple_organism_editor.py)

基于Pygame的简单编辑器，提供基本的AI生命体编辑功能。

##### 主要功能
- 可视化AI生命体结构编辑
- 工具组件的添加和配置
- 连接关系的创建和调整

#### 3.2 PyQt6编辑器 (pyqt_organism_editor.py)

基于PyQt6的现代化编辑器，提供更丰富的编辑功能和更好的用户体验。

##### 主要功能
- 现代化的GUI界面
- 拖拽式组件编辑
- 实时属性调整
- 多窗口布局
- 支持复杂的AI生命体设计

#### 使用示例
```python
from ai_organism.editor.ui.pyqt_organism_editor import PyQtOrganismEditor
from PyQt6.QtWidgets import QApplication

# 创建Qt应用
app = QApplication([])

# 创建PyQt6编辑器
editor = PyQtOrganismEditor()

# 显示编辑器
editor.show()

# 运行应用
app.exec()
```

## 编辑器工作流程

### 1. 创建新生命体
1. 选择编辑器类型（Pygame或PyQt6）
2. 设置生命体的基本属性
3. 添加工具组件（传感器、执行器、中枢大脑等）
4. 配置组件之间的连接关系
5. 保存为模板或直接用于模拟

### 2. 编辑现有生命体
1. 加载已有生命体或模板
2. 调整组件的位置和属性
3. 修改连接关系
4. 预览编辑结果
5. 保存修改或用于模拟

## 模块间关系

editor模块与其他模块的关系：
- 依赖core模块的生命体和记忆系统
- 依赖tools模块的工具组件
- 与simulation模块交互，支持将编辑好的生命体用于模拟

## 设计原则

- **模块化设计**：编辑器系统分为多个功能模块，便于维护和扩展
- **多种编辑器支持**：提供不同复杂度的编辑器，满足不同用户需求
- **命令模式**：支持undo/redo功能，提高编辑效率
- **模板系统**：支持模板的保存和加载，便于复用设计
- **实时预览**：提供实时预览功能，便于调整设计
