# 狼羊草生态系统模拟

[![Python Version](https://img.shields.io/badge/python-3.12+-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](../LICENSE)

## 📖 项目概述

本项目是一个独立的狼羊草生态系统模拟，模拟了狼、羊、草之间的捕食关系和生态平衡。该模拟基于AI生命体模拟器项目分离出来，专注于生态系统中不同物种间的相互作用和进化。

## 🎯 核心功能

### 生态系统模拟
- 模拟狼、羊、草之间的捕食关系
- 观察物种间的相互作用和生态平衡
- 基于记忆遗传的进化机制
- 实时种群数量统计和显示

### 智能行为
- 狼的捕食策略和记忆学习
- 羊的觅食和逃避行为
- 基于记忆的决策系统
- 适应环境变化的进化能力

### 可视化界面
- 基于Pygame的实时可视化模拟
- 支持模拟速度调节和暂停/继续
- 实时显示模拟统计数据

## 🚀 快速开始

### 安装依赖

确保已安装Python 3.12+和相关依赖：

```bash
# 使用uv安装依赖
uv install

# 或使用pip
pip install -r requirements.txt
```

### 运行模拟

直接运行生态系统模拟：

```bash
python -c "from wolf_sheep_grass_simulation import ecosystem_simulation; ecosystem_simulation.run_simulation()"
```

或创建一个简单的运行脚本：

```python
# run_ecosystem.py
from wolf_sheep_grass_simulation import ecosystem_simulation

ecosystem_simulation.run_simulation()
```

然后执行：
```bash
python run_ecosystem.py
```

## 🎮 使用说明

### 控制键
- `Space`：暂停/继续模拟
- `+`：增加模拟速度
- `-`：降低模拟速度
- `Q`：退出模拟

### 模拟参数

您可以在`ecosystem_simulation.py`中调整以下参数：
- 初始种群数量（狼、羊、草）
- 环境大小和资源分布
- 记忆遗传率和突变率
- 学习率和适应度函数
