# 基于记忆继承算法的AI生命体模拟器

## 项目概述

本项目是一个用于验证**记忆继承算法**的模拟器游戏。该模拟器从简单细胞开始，通过AI学习控制身体、积累经验，并将经验以结构化记忆的形式遗传给后代，最终观察智能行为的涌现和进化。

### 核心目标

构建一个**以"结构化记忆遗传"为核心机制、以"可扩展工具"为身体组件、以"AI学习控制"为驱动力的数字生命进化模拟沙盒**，验证记忆继承算法的可行性和有效性。

## 核心架构与设计要点

### 1. "工具"系统

#### 1.1 设计理念
将生物的基本功能单元抽象为"工具"，所有"工具"的核心是一个**输入输出函数**。这种设计确保了系统的**高度可扩展性**，可以轻松添加新的功能单元。

#### 1.2 工具类别

| 工具类型 | 功能描述 | 输入 | 输出 | 示例 |
|---------|---------|------|------|------|
| 传感器工具 | 感知环境信息 | 环境信息 | 神经信号 | 触觉传感器、光感传感器 |
| 效应器工具 | 执行物理动作 | 控制信号 | 物理力 | 肌肉效应器、纤毛效应器 |
| 非条件反射工具 | 固定连接的刺激-反应回路 | 传感器信号 | 效应器控制信号 | 触摸→收缩肌肉 |

#### 1.3 实现方式

定义了一个 `Tool` 基类，规定了统一的接口，所有具体工具都通过继承此基类实现。这种设计确保了系统的**高度可扩展性**，可以轻松添加新的工具类型。

### 2. AI学习与身体控制

#### 2.1 大脑设计

使用AI模型作为生物的"大脑"，负责：
- 接收来自所有传感器的输入
- 生成对各个效应器的控制信号
- 通过结果反馈学习控制策略

#### 2.2 学习过程

1. **初始状态**：生物出生时拥有基本的遗传记忆和本能行为
2. **感知环境**：通过传感器获取环境信息
3. **决策行动**：基于遗传记忆和当前感知生成控制信号
4. **执行动作**：效应器执行动作，影响环境
5. **学习反馈**：根据结果更新记忆

#### 2.3 学习产出

AI在试错中形成：
- **即时控制策略**：如何直接控制身体
- **条件反射**：特定情境下的固定反应模式
- **高级策略记忆**：复杂情境下的最优行为序列

### 3. 记忆继承算法

#### 3.1 记忆内容

需要被继承的是结构化的"经验知识"，而非原始感官数据流：

```
在 [某感官情境] 下，采取 [某套动作模式]，获得了 [高/低] 的奖励
```

#### 3.2 记忆基因

将经验封装为"记忆基因"数据结构，包含：
- **情境描述**：触发该记忆的环境条件
- **行动模式**：对应的效应器控制信号
- **成功概率**：该行动模式的成功率
- **记忆强度**：记忆的可靠性和遗传概率

#### 3.3 继承与变异机制

1. **继承选择**：后代以概率继承父辈的记忆基因，概率与记忆强度正相关
2. **记忆变异**：遗传过程中，记忆内容可能发生微调
3. **记忆衰减**：记忆随时间逐渐减弱，无用记忆被自然淘汰
4. **记忆强化**：成功经验会强化对应记忆的强度

### 4. 模拟器交互与可视化

#### 4.1 图形界面

- **节点表示**：每个"工具"以不同形状和颜色的节点表示
  - 绿色圆圈：触觉传感器
  - 黄色太阳：光感传感器
  - 红色条状：肌肉效应器
  - 青色波浪：纤毛效应器
- **连接表示**：工具间的连接以线条表示
  - 蓝色线条：兴奋性连接
  - 红色线条：抑制性连接
- **实时状态**：显示生物的能量、年龄、记忆数量等状态

#### 4.2 交互功能

- **查看详情**：点击生物查看详细信息
- **添加食物**：点击空地添加食物
- **创建生物**：通过快捷键创建新生物
- **重置模拟**：通过快捷键重置整个模拟
- **调整速度**：通过快捷键调整模拟速度
- **性能监控**：显示FPS和实体数量
