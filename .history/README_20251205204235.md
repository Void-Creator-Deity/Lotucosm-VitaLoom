# 基于继承算法实现的AI生命体

一个基于Python和继承算法的AI生命体模拟系统，支持可视化编辑、模拟进化和环境交互。

## 📋 项目概述

本项目实现了一个基于继承算法的AI生命体模拟系统，核心思想是通过模拟生物的进化过程，让AI生命体在环境中学习、适应和进化。系统融合了遗传算法、神经网络和环境交互等多种技术，实现了从简单到复杂的AI生命体进化。

## ✨ 核心功能

### 1. 可视化编辑器
- 基于PyQt6的现代化GUI编辑器
- 支持拖拽式创建和编辑AI生命体
- 可视化连接传感器、效应器和中枢管理器
- 实时属性调整和预览

### 2. 继承算法模拟
- 实现了Tool继承算法
- 支持记忆遗传和变异机制
- 可视化展示进化过程
- 支持多种环境配置

### 3. 环境交互系统
- 动态环境生成和管理
- 食物、光源、障碍物等环境元素
- 环境存档管理（保存、加载、编辑）
- 多环境支持

### 4. 模块化设计
- 核心组件（传感器、效应器、中枢管理器）
- 可扩展的工具系统
- 灵活的连接机制
- 支持多细胞生物结构

## 🛠️ 技术栈

| 技术/库 | 版本 | 用途 |
|--------|------|------|
| Python | 3.12+ | 核心开发语言 |
| PyQt6 | 6.6+ | GUI框架，用于编辑器和启动器 |
| Pygame | 2.6+ | 模拟环境渲染 |
| NumPy | 1.26+ | 数值计算 |
| uv | 0.1+ | 包管理工具 |

## 🚀 快速开始

### 1. 安装依赖

```bash
# 使用uv安装依赖
uv install

# 或者使用pip
pip install -r requirements.txt
```

### 2. 运行项目

```bash
# 启动现代化GUI启动器
uv run main.py

# 直接运行编辑器
uv run -m ai_organism.editor.ui.pyqt_organism_editor

# 直接运行模拟
uv run -m ai_organism.simulation.inheritance_simulation
```
