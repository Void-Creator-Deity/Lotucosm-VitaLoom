## 📖 项目概述

本项目是一个用于验证**记忆继承算法的AI生命体设计的模拟器，实现了基于继承算法的AI生命体模拟器，通过构建一个创新的记忆继承算法，探索AI生命体的核心技术，实现了一个用于验证**记忆继承算法**的模拟器。该模拟器从简单细胞开始，通过AI学习控制身体、积累经验，并将经验以结构化记忆遗传的形式遗传给后代的创新型记忆继承算法的模拟器游戏。

## 🎯 核心功能

- **记忆继承算法**：实现了一个用于验证**记忆继承算法**的模拟器，通过模拟生物的记忆继承机制，探索智能行为的涌现和进化过程。
