# 基于继承算法实现的AI生命体

## 项目概述

本项目是一个基于继承算法实现的AI生命体模拟系统，包含两个主要部分：

1. **Tool继承算法模拟器**（main.py）：基于Pygame的可视化模拟器，展示了一个由传感器、效应器和连接组成的AI生命体系统
2. **狼羊草生态系统**（ecosystem_simulation.py）：一个包含狼、羊、草的生态系统模拟，实现了记忆继承和学习机制

该系统通过模拟生物的感知、决策、行动和学习过程，探索AI生命体的进化和适应能力。

## 核心功能

### 1. Tool继承算法模拟器

#### 1.1 传感器系统
- **触觉传感器**：检测环境中的接触和压力
- **光感传感器**：检测环境中的光线强度

#### 1.2 效应器系统
- **肌肉效应器**：通过收缩产生力，改变生物体姿态
- **纤毛效应器**：通过摆动产生推进力，使生物体移动

#### 1.3 连接系统
- Tool之间的信号传递连接
- 支持兴奋性连接（蓝色）和抑制性连接（红色）
- 可视化的信号传递效果

#### 1.4 记忆系统
- **遗传记忆**：从父母继承的记忆，可能发生变异
- **学习记忆**：个体从经验中学习的新记忆
- **记忆衰减**：记忆随时间逐渐减弱
- **记忆变异**：繁殖时记忆可能发生微调

#### 1.5 物理模拟
- 位置、速度、加速度的物理计算
- 能量消耗和获取机制
- 碰撞检测和响应

#### 1.6 可视化交互
- 实时展示生物体的行为和状态
- 点击生物查看详细信息
- 点击空地添加食物
- 支持键盘快捷键操作

### 2. 狼羊草生态系统

#### 2.1 物种模拟
- **狼**：捕食者，以羊为食
- **羊**：食草动物，以草为食
- **草**：生产者，提供能量

#### 2.2 记忆继承机制
- 动物能够继承祖先的记忆
- 记忆包含情境、行为和结果
- 记忆强度影响遗传概率

#### 2.3 行为决策
- 基于记忆和本能的行为选择
- 支持探索新行为
- 从经验中学习和调整

#### 2.4 生态平衡
- 能量流动和物质循环
- 种群动态平衡
- 自动调整和重新初始化

#### 2.5 状态管理
- 支持保存和加载生态系统状态
- 命令行参数支持
- 详细的统计信息输出

## 安装与运行

### 1. 环境要求

- Python 3.8+
- Pygame
- NumPy

### 2. 依赖安装

使用uv包管理器安装依赖：

```bash
uv install
```

或使用pip：

```bash
pip install -r requirements.txt
```

### 3. 运行模拟器

#### 3.1 运行Tool继承算法模拟器

```bash
python main.py
```

**交互说明**：
- 点击生物查看详细信息
- 点击空地添加食物
- 按R键重置模拟
- 按F键在随机位置添加食物
- 按N键创建新生物

#### 3.2 运行狼羊草生态系统

```bash
# 新建生态系统
python 狼羊草杀.py

# 继续上次模拟
python 狼羊草杀.py continue
```

**输出说明**：
- 每50步打印一次基础统计信息
- 每1000步输出一次记忆快照
- 按Ctrl+C中断并保存状态

## 技术实现

### 1. 编程语言
- **Python 3.8+**：主要开发语言

### 2. 核心库
- **Pygame**：用于可视化界面和交互
- **NumPy**：用于数值计算和向量操作
- **Pickle**：用于生态系统状态保存和加载

### 3. 依赖管理
- **uv**：现代化的Python包管理器
- **pyproject.toml**：符合PEP 621的项目配置

### 4. 设计模式
- **继承模式**：通过类继承实现不同类型的Tool和动物
- **组合模式**：Organism类组合了多个Tool和记忆
- **观察者模式**：环境变化时通知生物体
- **状态模式**：生物体根据状态调整行为
