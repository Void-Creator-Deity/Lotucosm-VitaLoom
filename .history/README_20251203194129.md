# 基于记忆继承算法的AI生命体模拟器

[![Python Version](https://img.shields.io/badge/python-3.12+-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## 📖 项目概述

本项目是一个创新的AI生命体模拟器，实现了基于**记忆继承算法**的智能进化系统。该模拟器从简单的AI生命体开始，通过学习控制身体、积累经验，并将经验以结构化记忆的形式遗传给后代，探索智能行为的涌现和进化过程。

核心功能是**AI生命体记忆继承模拟**，验证记忆遗传机制的有效性，观察智能行为的涌现和进化。

## 🎯 核心功能

### 记忆继承算法
- 实现了结构化记忆的遗传机制
- 支持AI生命体通过经验学习和记忆遗传进化
- 可观察智能行为的涌现过程
- 优化的记忆检索和匹配算法，提高运行效率

### 单模式模拟系统
- **AI生命体模式**：从简单细胞开始，通过学习和记忆遗传进化

### 可视化界面
- 基于Pygame的实时可视化模拟
- 支持模拟速度调节和暂停/继续
- 实时显示模拟统计数据
- 增强的按钮交互效果和状态显示

### 编辑器支持
- 传统Pygame编辑器，提供基本编辑功能
- 全新PyQt6编辑器原型，提供IDE风格的编辑体验
- 支持项目管理、生物编辑和属性调整

### 优化的性能
- 核心算法性能优化，支持更大规模模拟
- 记忆管理优化，防止内存无限增长
- 高效的记忆检索和匹配机制

### 可扩展架构
- 模块化设计，支持添加新的物种和行为
- 易于扩展的记忆遗传机制
- 支持自定义环境参数

## 🚀 快速开始

### 安装依赖

```bash
# 使用uv安装依赖
uv install

# 或使用pip
pip install -r requirements.txt
```

### 运行模拟

```bash
# 启动模式选择器
python main.py
```

在模式选择器中，您可以选择运行：
1. **AI生命体记忆继承模拟**
2. **狼羊草生态系统模拟**

## 🎮 使用说明

### 控制键
- `Space`：暂停/继续模拟
- `+`：增加模拟速度
- `-`：降低模拟速度
- `Q`：退出模拟

### 模拟参数

您可以在相应的模拟类中调整以下参数：
- 种群数量和初始状态
- 环境大小和资源分布
- 记忆遗传率和突变率
- 学习率和适应度函数
