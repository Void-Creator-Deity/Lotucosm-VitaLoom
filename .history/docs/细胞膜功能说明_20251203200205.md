# 细胞膜功能实现说明

## 1. 细胞膜的核心功能

细胞膜在AI生命体系统中扮演着重要角色，作为细胞的物理边界和功能集合体，它具有以下核心功能：

| 功能类型 | 描述 |
|---------|------|
| **物理边界** | 定义细胞的物理范围，所有传感器和效应器必须位于细胞膜内或表面 |
| **自动吞噬** | 自动吞噬小型物体，增加细胞能量 |
| **信息传递** | 作为感受器和效应器的集合体，处理环境信息并传递控制信号 |
| **细胞间通信** | 支持细胞间信息传递，为多细胞生物奠定基础 |

## 2. 细胞膜的实现细节

### 2.1 类继承关系

```
Tool (基类)
└── MembraneTool (细胞膜)
```

### 2.2 核心属性

| 属性 | 描述 |
|------|------|
| `position` | 细胞膜中心位置 |
| `radius` | 细胞膜半径 |
| `color` | 细胞膜颜色 |
| `border_color` | 边框颜色 |
| `border_width` | 边框宽度 |
| `permeability` | 通透性系数 |
| `auto_ingest_threshold` | 自动吞噬阈值 |
| `cell_communication_enabled` | 细胞间通信启用标志 |

### 2.3 关键方法

#### `is_inside(position)`
- 检查位置是否在细胞膜内
- 所有传感器和效应器必须位于细胞膜内或表面

#### `auto_ingest(objects)`
- 自动吞噬小型物体
- 阈值判断：物体半径 ≤ 细胞膜半径 * 0.3

#### `cell_to_cell_communication(other_cell)`
- 细胞间通信接口
- 支持多细胞生物发展

## 3. 细胞膜与其他组件的关系

### 3.1 组件位置限制

- **传感器(Sensor)**：必须位于细胞膜内或表面
- **效应器(Actuator)**：必须位于细胞膜内或表面
- **中枢管理器(Central Brain)**：通常位于细胞中心
- **连接(Connection)**：可以跨越细胞膜，但主要在内部传递信号

### 3.2 信号流程

```
环境刺激 → 传感器 → 连接 → 中枢管理器 → 连接 → 效应器 → 动作
            ↑           ↑           ↑
            └── 细胞膜 ─┘           └── 细胞膜 ─┘
```

### 3.3 控制权限

- 反射路径：传感器 → 连接 → 效应器（不受中枢管控）
- 中枢路径：传感器 → 连接 → 中枢 → 连接 → 效应器（中枢控制）
- 中枢控制权限 > 反射控制

## 4. 细胞膜的使用示例

### 4.1 基本细胞结构

```python
# 创建一个完整的细胞
organism = Organism("cell_1", (100, 100))

# 添加细胞膜
membrane = MembraneTool("membrane_1", (0, 0), radius=50)
organism.add_membrane(membrane)

# 添加中枢管理器
brain = CentralBrainTool("brain_1", (0, 0))
organism.add_central_brain(brain)

# 添加传感器和效应器
sensor = LightSensor("light_sensor_1", (20, 0))
organism.add_sensor(sensor)

actuator = CiliaActuator("cilia_1", (-20, 0))
organism.add_actuator(actuator)

# 建立连接
organism.connect_tools("light_sensor_1", "brain_1")  # 感光→中枢
organism.connect_tools("brain_1", "cilia_1")          # 中枢→纤毛
```

### 4.2 细胞膜作为感受器和效应器

细胞膜可以同时作为特殊的感受器和效应器：

```python
# 细胞膜作为感受器，感知环境变化
membrane_sensor = MembraneSensor("membrane_sensor", (0, 0))

# 细胞膜作为效应器，控制细胞行为
membrane_actuator = MembraneActuator("membrane_actuator", (0, 0))
```
