# 细胞膜设计说明

## 1. 设计原则

根据用户的设计思路，细胞膜的设计应遵循以下原则：

1. **独立的物理边界**：细胞膜是一个独立的圆环，用于定义细胞的物理边界
2. **其他器官的位置限制**：所有传感器、效应器和中枢只能在细胞膜内或细胞膜表面
3. **无直接信号传递功能**：细胞膜本身不能被连线，它不是信号传递的通道
4. **功能由其他tool实现**：细胞膜的功能（如感知、物质交换）由细胞膜上的其他tool实现
5. **细胞中枢独立存在**：细胞中枢是一个独立的tool，位于细胞膜内

## 2. 实现方案

### 2.1 细胞膜结构

- **形态**：独立的圆环
- **颜色**：蓝色
- **大小**：可调整
- **位置**：可移动

### 2.2 其他器官的位置限制

- **传感器**：只能在细胞膜内或表面
- **效应器**：只能在细胞膜内或表面
- **中枢**：只能在细胞膜内或表面

### 2.3 连接规则

- **禁止**：直接连接细胞膜
- **允许**：传感器→中枢、中枢→效应器、传感器→效应器（反射）

## 3. 编辑器实现

### 3.1 简化设计

1. **移除不必要的连线限制**：不再尝试限制连线，让用户自由连接
2. **简化细胞膜绘制**：只绘制一个圆环，不包含中心节点
3. **修复绘图API问题**：使用整数绘图API，避免类型转换错误
4. **位置验证**：确保新添加的节点和移动的节点只能在细胞膜内或表面

### 3.2 实现步骤

1. 移除生物体节点的中心绘制
2. 只绘制细胞膜圆环
3. 修复编辑器的绘图API问题
4. 添加位置验证，确保节点只能在细胞膜内或表面

## 4. 代码修改计划

1. **修改pyqt_organism_editor.py**：
   - 简化细胞膜绘制，只绘制圆环
   - 修复绘图API，使用整数类型
   - 添加位置验证，确保节点只能在细胞膜内或表面
   - 禁止直接连接细胞膜

2. **修改organism.py**：
   - 确保细胞膜是独立的组件
   - 确保其他组件只能在细胞膜内或表面
   - 确保细胞中枢是独立的组件

3. **修改相关工具类**：
   - 确保细胞膜不能被直接连接
   - 确保其他工具只能在细胞膜内或表面

## 5. 预期效果

- 细胞膜显示为一个蓝色圆环
- 其他器官（传感器、效应器、中枢）只能在细胞膜内或表面
- 禁止直接连接细胞膜
- 编辑器能够正常运行，无绘图错误
- 支持节点的添加和移动，自动限制在细胞膜内
